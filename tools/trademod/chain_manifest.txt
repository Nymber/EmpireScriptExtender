# ------------------------------------------------------------------ recipes
# output | qty | input1 | qty1 | input2 | qty2
# Read by the ESE script, NOT by the engine - Empire has no native concept of a
# building consuming a commodity, so conversion is simulated per turn.
# RECIPES ARE PER BATCH - the 2nd field is how many are made from the inputs
# that follow. That matters enormously now that a unit costs one musket PER
# MAN: a 200-man regiment is 200 muskets, so at a 1-musket-per-1-timber ratio
# a single regiment would eat 200 timber, which is more than the entire map
# produces. Batch ratios keep the raw tier on a scale the map can supply.
RECIPE|res_steel|4|res_iron|2|res_coal|3
RECIPE|res_gunpowder|4|res_saltpetre|3|res_coal|1
RECIPE|res_ammunition|4|res_gunpowder|2|res_lead|1

# ----------------------------------------------------------------- buildings
# chain | slot | commodity | base_output | base_cost | display name
#       | art[:levels] | chain_category | prestige
#
# Three levels are generated per chain (output x1/1.7/2.7, cost x1/2/4), which
# mirrors the rum distillery that is already proven to build and produce.
#
# The SLOT is the localisation: a coal mine can only exist where a coal slot
# was placed, and a foundry needs an industrial town. Empire already ships
# town-metal and settlement_ordnance, so manufacturing needs no new slot types.
#
# ART (7th field) - `family` or `family:l1,l2,l3` to pick which three models of
# a family the three levels use. Every generated key is validated against
# vanilla_artpieces.txt, so a typo is a build error rather than a silent exit
# before the main menu.
#
#   Empire ships NO mine and NO powder-mill model for European/Indian/Ottoman
#   cultures - the only pit mines are NA_/NAN_, level 1 only - so the extractive
#   buildings borrow the closest industrial look rather than repeat one model
#   eleven times. city_artillery has SIX levels, which is what lets the three
#   ordnance buildings each get a distinct slice of the same progression.
#
# CHAIN_CATEGORY (8th) - vanilla uses money/military/agriculture/happiness/
# government/research. It groups the chain in the construction UI.
#
# PRESTIGE (9th) - `economic=N`, `military=N`, `naval=N`; applied to the GRAND
# level only, matching vanilla's scale (10/15/20).
# The rum distillery came first, as a separate hand-built pack, and was left
# out of this manifest - so when the other ten got proper art it kept the SUGAR
# PLANTATION model it had been given as a stand-in, i.e. the cane field rather
# than the distillery. It is a producing building like any other and belongs
# here, or the next regeneration forgets it again.
#
#   slot:     TWO slots, written with +
#   10th fld: the level-name stem, because the chain key is `rum` but the
#             levels are small/large/grand_rum_distillery, and both spellings
#             are already referenced by shipped description keys and by
#             anything built in an existing campaign.
#   art:      town_happy (EU/IND/OTT, levels 1-4) is the brewery/tavern family.
#             resource_vineyards would be the ideal fit but exists ONLY for EU,
#             even in warscape_rigid_tables, so it cannot cover five cultures.
BLD|rum|caribbean+cuba|res_rum|15|2500|Rum Distillery|town_happy:1,2,3|money|economic=5|rum_distillery
